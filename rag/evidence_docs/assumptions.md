# Assumptions Used in the Synthetic Oncology Demand POC

This project uses a synthetic oncology market inspired by metastatic NSCLC-like demand planning. The assumptions are not presented as real commercial facts. They are used to create a controlled case study for forecasting, scenario analysis, uncertainty, and RAG-grounded explanation.

## Assumption Types

The project separates assumptions into three broad groups:

1. Evidence-backed or evidence-informed proxy assumptions
2. Synthetic design assumptions
3. Scenario assumptions

Evidence-backed or evidence-informed assumptions use public sources as directional anchors. Synthetic design assumptions are chosen to create a plausible but fictional oncology market. Scenario assumptions are user-controlled planning inputs used to test possible futures.

## Important Assumption Areas

The main assumption categories are:

- epidemiology
- diagnosis
- biomarker prevalence
- therapy eligibility
- market access
- treatment allocation
- persistence and discontinuation
- competition and patient-segment overlap
- utilization per patient-month
- supply constraint

## Key Principle

Synthetic assumptions must never be described as real-world validated evidence. The purpose of the project is methodological: to show how patient-flow logic, forecast governance, uncertainty, and scenario analysis can support pharmaceutical planning.
