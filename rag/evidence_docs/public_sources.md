# Public Sources and Evidence Notes

This project is a synthetic case study. Public sources are used only as proxy anchors for selected assumptions.

## Population Growth

World Bank population growth data was used as a public-data-informed proxy for the annual population growth assumption.

Source:
https://data.worldbank.org/indicator/SP.POP.GROW?locations=US

## NSCLC Epidemiology Proxy

Published NSCLC epidemiology was used as a directional proxy for incidence and prevalence assumptions.

Source:
https://pubmed.ncbi.nlm.nih.gov/34673888/

## NSCLC Clinical Context

Public clinical literature was used for broad context around NSCLC disease burden, staging, and treatment relevance.

Source:
https://pmc.ncbi.nlm.nih.gov/articles/PMC4931124/

## Evidence Limitation

The project does not claim real-world clinical validation. The market is synthetic. Public sources only make selected assumptions more plausible and explainable.
